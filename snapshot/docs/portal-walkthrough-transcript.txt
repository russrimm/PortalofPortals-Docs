=== INTRODUCTION ===
[pause]
Welcome to *PORTAL 360°* - a comprehensive, unified administration portal designed for IT professionals and Managed Service Providers managing Microsoft cloud environments. [pause]
Portal 360° is your *single pane of glass* for administering Microsoft 365, Azure Infrastructure, Power Platform, and Intune endpoint management. Built with Next.js and React, this modern web application *eliminates the need to switch between multiple admin portals*, saving time and reducing complexity for IT teams managing enterprise environments. [pause]
The portal provides *real-time insights*, *advanced analytics*, *AI-powered exception analysis*, and comprehensive reporting capabilities across your entire Microsoft ecosystem. Whether you're managing device compliance, analyzing costs, monitoring security posture, or deploying Azure resources, Portal 360° brings everything together in one intuitive interface with dark mode support and responsive design. [pause]
Let's walk through each section of the portal, starting from the top of the left navigation menu.
[pause]

=== MICROSOFT 365 SECTION ===
[pause]
The Microsoft 365 section is your hub for managing users, devices, applications, and licensing. [pause]
Under Applications, we have three critical pages: [pause]
*App Registrations* shows all application registrations in your tenant. You can view client IDs, redirect URIs, API permissions, and certificate details. This is essential for managing custom applications and service principals that integrate with your Microsoft services. [pause]
*Enterprise Applications* provides visibility into all enterprise applications, including both Microsoft and third-party SaaS applications. You can see user assignments, single sign-on configurations, and conditional access policies applied to each application. [pause]
*Service Principals* displays the service principal directory, showing the security identities used by applications to access Azure resources. This is critical for understanding application permissions and managing service account access. [pause]
The *Licensing* page shows all subscribed SKUs and licenses across your Microsoft 365 tenant. You can see consumed units, available units, and per-SKU license assignments. This helps with license optimization and budgeting decisions. [pause]
Under Microsoft Teams, the *Teams List* displays all Teams in your organization with member counts, privacy settings, and creation dates. You can quickly audit team sprawl and identify inactive or misconfigured teams. [pause]
*Transcripts* allows you to subscribe to call transcripts for Teams meetings, providing valuable records for compliance and documentation purposes.
[pause]

=== AZURE INFRASTRUCTURE SECTION ===
[pause]
Azure Infrastructure is where you manage your cloud resources, costs, monitoring, and compliance. [pause]
Under Resource Management, the *Resource Explorer* provides a powerful interface to query Azure resources using *Azure Resource Graph*. You can run KQL-style queries to find resources across subscriptions, filter by resource type, tags, or location, and export results. This is *invaluable for resource inventory and compliance reporting*. [pause]
*Virtual Machines* displays all Azure VMs across your subscriptions with power state, size, location, and cost information. You can start, stop, and manage VMs directly from this interface. [pause]
*Deploy Resources* allows you to deploy Azure infrastructure using Bicep templates. You can paste Bicep code, validate the template, and deploy resources to target subscriptions and resource groups - all from the web interface. [pause]
*Deployment Stacks* introduces lifecycle management for Azure resources with the new Deployment Stacks feature. You can create, update, and delete entire resource stacks while maintaining dependencies and preventing drift. [pause]
*Azure Monitor Metrics* provides access to metric definitions and time-series data for Azure resources. You can select resources from any subscription, choose from available metrics like CPU percentage or network throughput, configure time ranges and aggregation intervals, and visualize trends with *interactive Recharts-powered line charts*. The charts support real-time data updates, configurable time granularity - 1, 5, 15, 30, 60 minutes - and smooth animations for an enhanced monitoring experience. Multiple time series can be compared side-by-side, making it easy to identify patterns, anomalies, and correlations across different metrics. [pause]
Under Health and Compliance, *Policies and Compliance* provides comprehensive Azure Policy management with multiple views. The *Active Policies* tab is your primary dashboard, showing all active policy assignments with *real-time compliance percentages*, color-coded indicators - green for 90% and above, yellow for 70 to 89%, red below 70% - resource counts, and *one-click remediation access*. Each policy card displays the policy name, description, enforcement mode, compliant and non-compliant resource counts, and a compliance progress bar. You can drill into specific policy violations, view detailed compliance states, manage policy assignments at subscription or resource group scope, and initiate remediation tasks for non-compliant resources - all from a *unified interface that makes governance actionable*. [pause]
*Advisor* displays your Azure Advisor score and recommendations across five categories: Cost, Security, Reliability, Operational Excellence, and Performance. Each recommendation includes potential impact, detailed descriptions, affected resources, and direct action steps to improve your Azure environment. Recommendations are *prioritized by impact level* - High, Medium, Low - helping you focus on changes that will make the biggest difference to your cloud operations. [pause]
Under Cost and Billing, the *Cost Overview* dashboard shows your current month charges, cost forecasts, and marketplace spending. You can visualize spending trends and identify cost anomalies before they become budget issues. [pause]
*Azure Cost Details* provides granular cost and usage reports with the ability to filter by date range, subscription, resource group, and service. You can export detailed billing data for charge-back and show-back reporting. [pause]
*Budgets* lets you create and manage cost budgets with alert thresholds. You can set budgets at subscription or resource group level and receive notifications when spending exceeds defined thresholds. [pause]
*Forecasts* predicts future Azure costs based on historical usage trends and consumption patterns. This helps with financial planning and budget allocation for cloud resources. [pause]
*Reservations* shows reservation recommendations and utilization metrics. You can identify opportunities to save money by purchasing reserved instances for predictable workloads. [pause]
Under Monitoring and Logs, the *Log Analytics Explorer* provides an editable KQL query interface to Azure Monitor Logs. You can write queries against log analytics workspaces to analyze application logs, performance data, and security events. [pause]
*App Insights AI Analysis* is a powerful feature that uses artificial intelligence to analyze Application Insights exceptions. The AI agent examines stack traces, error messages, and application context to provide *root cause analysis and remediation suggestions* - dramatically reducing time to resolution for production issues.
[pause]

=== POWER PLATFORM SECTION ===
[pause]
Power Platform management covers environments, capacity, and governance for low-code applications. [pause]
Under Environment Management, *Environments* is the centerpiece page showing all Power Platform environments with detailed information including database capacity, storage consumption, Dataverse organization details, and security group assignments. You can expand each environment to view flows, solutions, connection references, and Copilot Studio agents. The page features *flow run history*, *bot configuration viewers*, and comprehensive resource management. [pause]
For *Power Automate flows*, the portal provides *deep inspection capabilities in read-only mode*, allowing you to gain complete insight into all flows without any risk of accidental modification. You can view flow definitions, examine triggers and actions, analyze connection references, review error details, and track run history - all with *zero risk of changing production flows*. This read-only approach gives administrators and auditors the confidence to explore flow logic, understand automation patterns, identify dependencies, troubleshoot issues, and document business processes without fear of disrupting critical workflows. The flow viewer displays the complete flow JSON structure, action parameters, conditional logic branching, and variable usage, making it an *invaluable tool for governance, compliance reviews, and knowledge transfer*. [pause]
For *Power Apps*, clicking the apps badge opens a detailed modal showing all canvas and model-driven apps in the environment. Each app has *inline View and Launch buttons* directly next to the app name for quick access. The View button opens an expandable detail panel showing comprehensive app properties including background images, *connection references with full API specifications*, *app owner contact information* with direct email and Microsoft Teams links, sharing statistics, featured and hero app status, and complete connector details with icons. This gives you *complete visibility into app configuration, dependencies, and ownership at a glance*. [pause]
Solutions can be exported or analyzed using AI. The *AI Analyze feature* uses Azure OpenAI to examine solution composition, identify potential issues, recommend best practices, and provide actionable insights about flows, apps, connectors, and custom components. The analysis handles large solutions with *intelligent timeout management*, processing solutions up to 10 minutes with detailed progress tracking and graceful error handling for complex exports. [pause]
*Tenant Settings* displays Power Platform tenant-level configuration including feature flags, governance policies, and administrative settings that apply across all environments. [pause]
*Tenant Capacity Details* shows consumption metrics for database storage, file storage, and log capacity across your Power Platform tenant. This helps you understand capacity utilization and plan for growth. [pause]
*Billing Plans* displays environment-level billing plans and policies, showing which environments are mapped to specific Azure subscriptions for pay-as-you-go billing. [pause]
Under Data and Governance, *DLP Policies* shows Data Loss Prevention policies that control connector usage across Power Platform environments. You can see business data groups, blocked connectors, and policy assignments to prevent data exfiltration. [pause]
*Cross Tenant Reports* provides visibility into cross-tenant connections in Power Platform. This is critical for understanding data flows between your organization and external tenants, ensuring compliance with data residency requirements.
[pause]

=== ENDPOINT MANAGEMENT SECTION ===
[pause]
Endpoint Management is your Intune and device management hub. [pause]
Under Status and Monitoring, *Devices* displays all managed devices in your organization with detailed information including device names, operating systems, compliance status, last check-in times, and ownership. You can *quickly identify non-compliant devices*, search by device name, and take action to remediate issues. [pause]
*Compliance Status* shows device compliance policy status across all managed endpoints. You can see compliant, non-compliant, and error state devices with filtering by compliance policy name. [pause]
*Configuration Status* displays configuration profile deployment status showing successful, pending, failed, and error states for device configuration policies. [pause]
*Encryption Report* provides device encryption status for BitLocker on Windows and FileVault on macOS. This is *essential for security compliance and data protection requirements*. [pause]
*Windows Update Status* shows Windows Update deployment status for all managed Windows devices with update states, deferral periods, and quality update compliance. [pause]
*Enrollment Report* displays device enrollment trends and failures over time. You can identify enrollment bottlenecks and troubleshoot onboarding issues. [pause]
*Intune Audit Logs* shows administrative actions and changes in Intune. You can track who made what changes and when, providing an audit trail for compliance. [pause]
Under Policies and Configuration, *Policy Assignments* provides a unified view of policy assignments across both compliance and configuration policies. You can see target groups, assignment status, and policy intent. [pause]
*Device Compliance* displays device compliance policies with their settings and targeting. You can create, edit, and delete compliance policies that define *minimum security requirements* for device access. [pause]
*Device Configurations* shows device configuration profiles including Wi-Fi settings, VPN configurations, email profiles, and restriction policies. [pause]
*Settings Catalog* provides access to configuration policies using the Settings Catalog approach - Microsoft's modern way to configure device settings with *thousands of available settings* in a searchable catalog. [pause]
*Autopilot Profiles* displays Windows Autopilot deployment profiles used for zero-touch device provisioning. You can see OOBE configuration, device group assignments, and deployment mode settings. [pause]
Under Applications, *Intune Managed Apps* shows all applications deployed through Intune with comprehensive platform support including iOS, Android, Windows, macOS, and web apps. The page features *advanced filtering* by platform and publisher, sortable columns, and detailed app information. Android apps display package IDs, version codes, app store URLs, and minimum supported Android versions. Each app is clickable to view full details including installation commands, uninstall commands, content versions, featured status, dependencies, and supersedence relationships. Apps show assignment status with quick access to view assigned groups, making it easy to *audit app deployments* and identify which apps are actively assigned versus available for deployment. [pause]
Under OS Updates, *Windows Update Status* provides deployment tracking for quality and feature updates across your Windows estate. [pause]
*Known Issues by OS* displays Windows Update known issues organized by operating system build. This helps you understand potential problems before deploying updates. [pause]
*Windows Updates Catalog* is a searchable database of Windows updates and CVE vulnerabilities. You can research specific KB articles and understand security update contents.
[pause]

=== SECURITY AND IDENTITY SECTION ===
[pause]
Security and Identity focuses on users, access control, threat detection, and authentication monitoring. [pause]
Under Identity Management, *Users* displays all user accounts in your Entra ID tenant with sign-in status, licenses, account details, and profile information. You can search, filter, and export user information. [pause]
*Groups* shows security and distribution groups with membership counts, group types, and ownership. This is essential for access management and email distribution. [pause]
Under Conditional Access, *Conditional Access Policies* displays all CA policies with their state, conditions, grant controls, and session controls. You can see which policies are enabled, report-only, or disabled and understand the access control requirements applied to your organization. [pause]
*Named Locations* shows IP and country-based named location definitions used in conditional access policies to define trusted network locations. [pause]
*Authentication Contexts* displays authentication context class references that allow for step-up authentication based on resource sensitivity. [pause]
*Cross Tenant Access* provides configuration for B2B collaboration and B2B direct connect with external organizations, controlling how users access resources across tenant boundaries. [pause]
*Security Defaults* shows the enforcement status of Microsoft's baseline security defaults that protect your tenant with fundamental security policies. [pause]
*Authorization Policy* displays tenant-level authorization settings that control default user permissions and guest access capabilities. [pause]
*App Protection Status* shows Mobile Application Management app protection policy status. You can see which users have MAM policies applied and track compliance with mobile app security requirements. [pause]
*Risky Users* displays users flagged by Entra ID Identity Protection with risk levels, risk detections, and risk state. This helps you *identify compromised accounts* and take remediation action through password reset or risk dismissal. [pause]
Under Security Posture, *Secure Score* shows your Microsoft Secure Score with *actionable recommendations* to improve your security baseline. Each recommendation includes point value, category, impact, and implementation guidance. You can track score history and measure security improvements over time. [pause]
*Security Alerts* displays Microsoft Defender security alerts with severity, status, alert type, and affected entities. You can triage and investigate security incidents from this centralized view. [pause]
*Defender for Endpoint* shows alerts, devices, and vulnerabilities from Microsoft Defender for Endpoint. This provides *endpoint detection and response capabilities* with threat intelligence, software vulnerability assessments, and machine risk scores. [pause]
*NIST NVD CVE Database* provides access to the National Vulnerability Database for researching Common Vulnerabilities and Exposures. You can search by CVE ID, keyword, or vendor to understand vulnerability details, CVSS scores, affected products, and available patches. [pause]
Under Sign-In Activity, *User Sign-Ins* displays user authentication logs with success and failure events. You can filter by user, application, location, IP address, and result status to investigate sign-in issues and identify suspicious authentication attempts. [pause]
*Service Principal Sign-Ins* shows service principal authentication activity - critical for understanding automated application access patterns, API calls, and service-to-service authentication flows. [pause]
*Blocked Sign-Ins* displays sign-ins blocked by conditional access policies. This helps you understand access denials, identify policy misconfigurations, and validate that your security controls are working as intended. [pause]
*MFA Sign-Ins* shows multi-factor authentication success and failure metrics. You can track MFA adoption rates, identify authentication problems, and monitor MFA method usage across your organization. [pause]
Under Audit Logs, *Audit Logs* displays Entra ID directory audit logs showing administrative changes, user modifications, group management activities, and application operations. This provides a comprehensive audit trail for compliance and security investigations. [pause]
*Audit Log Queries* provides *cross-workload audit log search capabilities*. You can search across Exchange mailbox activities, SharePoint file access, Teams meetings and chats, and Entra ID directory operations in one unified query interface. [pause]
*Provisioning Logs* shows user provisioning activities from HR systems or identity governance solutions. You can track automated account creation, updates, deletions, and synchronization status. [pause]
*Intune Audit Logs* provides a dedicated view of Intune administrative actions for device management change tracking, showing who made policy changes, app deployments, and device actions.
[pause]

[pause]
Tenant Health keeps you informed about service status, incidents, and changes across your Microsoft ecosystem. [pause]
*Service Health* displays current service health status for all Microsoft 365 services including Exchange Online, SharePoint, Teams, and Entra ID. You can see active incidents with user impact details, planned maintenance windows, service advisories, and historical health trends. This gives you *real-time visibility* into service disruptions affecting your users. [pause]
*Emerging Issues* shows Azure emerging issues that may impact your subscriptions. This *early warning system* helps you prepare for potential service disruptions, performance degradations, or regional outages before they fully materialize. [pause]
*Service Announcements* displays official Microsoft service announcements about new features, deprecations, breaking changes, and important updates. You can filter announcements by service area and stay informed about upcoming changes that may require action. [pause]
*ServiceNow Incidents* integrates with ServiceNow to display incidents with status, priority, assignment group, affected CIs, and resolution details. This brings your ITSM data into the unified portal experience, allowing you to correlate Microsoft service health with your internal incident management. [pause]
*Product News and Release Plans* links to the external Microsoft 365 roadmap where you can explore upcoming features, preview capabilities, and release timelines across the Microsoft ecosystem.

This is perfect for compliance documentation, security assessments, tenant audits, and creating baseline snapshots of your environment. [pause]

You can see adoption trends for Exchange mailbox usage, Teams active users, SharePoint site visits, OneDrive file syncs, and Viva Engage engagement - helping you measure Microsoft 365 ROI and identify underutilized services. [pause]
*M365 App User Counts* displays Microsoft 365 desktop app usage metrics showing which applications are being actively used across your organization. This includes Word, Excel, PowerPoint, Outlook, and OneNote usage by platform, helping you understand application adoption and licensing optimization opportunities.
