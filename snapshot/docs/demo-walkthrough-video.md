## Recording Checklist

1. Start from a signed-in tenant with representative data across Entra, Intune, Azure, and Power Platform.
2. Use fullscreen browser mode at 1920×1080.
3. Keep dark mode enabled for visual consistency.
4. Use smooth zoom and cursor movement on key metrics, status pills, and primary action buttons.
5. Blur or scrub sensitive tenant data — user names, email addresses, tenant IDs, IP addresses, and any secrets — before publishing.
6. Record narration using [`video-transcript.md`](./video-transcript.md). Section timestamps in the transcript align 1:1 with this plan.
7. Export with captions enabled (SRT can be generated from the transcript sections).
8. If a menu label differs in your tenant due to feature flags or permissions, keep the same flow intent and use the closest equivalent page while preserving timestamp order.
